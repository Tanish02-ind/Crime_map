# Frontend (React + Vite)

## Prerequisites
- Node.js (v18+)
- npm

## Setup

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run the Development Server:**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173`.

## Docker
You can also run the frontend via Docker Compose from the root directory:
```bash
docker-compose up frontend
```
