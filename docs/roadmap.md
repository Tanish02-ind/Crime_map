# Project Roadmap

## Phase 1: Foundation & Infrastructure (Weeks 1-3)
- [ ] Set up project repositories (Frontend & Backend).
- [ ] Configure PostgreSQL + PostGIS database.
- [ ] Implement basic authentication and RBAC (Citizen vs. Police).
- [ ] Implement ID verification mockups/services.

## Phase 2: Core Reporting & Mapping (Weeks 4-6)
- [ ] Build the interactive map using React, Leaflet, and OpenStreetMap.
- [ ] Develop the REST API for submitting standard reports.
- [ ] Implement photo upload and metadata extraction.
- [ ] Build the Police Dashboard UI (Stats: Total, Pending, Investigating, Resolved).

## Phase 3: Real-Time Features & Safety (Weeks 7-9)
- [ ] Integrate Socket.IO for real-time bi-directional communication.
- [ ] Implement the "Violent Crime" emergency broadcast feature to nearby citizens.
- [ ] Develop live tracking and status runner for ongoing incidents.
- [ ] Setup initial Live Video feed infrastructure.

## Phase 4: AI & Advanced Analytics (Weeks 10-12)
- [ ] Integrate the AI Complaint Assistant for NLP text extraction.
- [ ] Implement Mapbox Heat Map layers for crime trends.
- [ ] Develop the false-complaint prevention logic (Geospatial proximity checks).
- [ ] Refine the UI/UX for incident transparency and tracking (Complaint ID generation).

## Phase 5: Testing, Polish & Launch (Weeks 13-15)
- [ ] End-to-end testing of real-time alerts.
- [ ] Penetration testing and privacy audits.
- [ ] Beta release to a localized metropolitan area.
- [ ] Collect feedback and optimize database spatial queries.
